# Práctica Profesionalizante

Trabajos de la materia Práctica Profesionalizante de la Tecnicatura en Análisis de Datos e Inteligencia Artificial, desarrollados en la entidad Punto Digital Villa Ojo de Agua.

## Notebooks

| Notebook | Contenido |
|----------|-----------|
| [PP_TP_PD.ipynb](notebooks/PP_TP_PD.ipynb) | Hito 1: inspección y limpieza de la base de datos de usuarios y asistencias del Punto Digital (calidad de datos, normalización de DNIs como clave primaria, unificación de tablas). |
| [PP_TP_PD-2.ipynb](notebooks/PP_TP_PD-2.ipynb) | Hito 2: preprocesamiento y Análisis Exploratorio de Datos (EDA): distribución de asistencias, perfiles de usuarios, series temporales y visualizaciones. |

> Los notebooks se publican con outputs parcialmente sanitizados: se eliminaron las salidas que mostraban datos personales (DNIs y nombres de los usuarios de la base). El dataset utilizado **no está incluido** por contener datos personales. Todos los demás gráficos y resultados se mantienen.

## Informes

- `informes/Ficha_Proyecto_PuntoDigital.docx` — Ficha de proyecto: identificación del problema, objetivos, valor para la entidad y datos del proyecto.
- `informes/Punto_Digital_Data_Intelligence.pdf` — Presentación grupal del proyecto "Punto Digital ODA: consolidación, análisis y automatización" (16 páginas).

## Contexto del proyecto

La institución no contaba con un sistema unificado de registro de asistencias, lo que generaba dispersión de información, duplicación de datos y pérdida de registros históricos. El trabajo abarcó la recolección, limpieza, análisis exploratorio y propuesta de automatización sobre esas bases.

## Temas cubiertos

- Calidad y limpieza de datos (deduplicación, normalización de identificadores)
- Unificación de tablas relacionales (usuarios, asistencias, actividades)
- Análisis exploratorio de datos (EDA)
- Visualización con Matplotlib/Seaborn
- Series temporales de asistencia
